# CGV 개인 예매 알림

**개인용 상영 스케줄 알림 도구이며 자동 예매 기능 없음**

## 현재 상태: 감시 중지

2026-09-22에 Cloudflare Cron을 제거하고 `MONITOR_ENABLED=false`로 설정했습니다. CGV 조회와 Discord 예매 알림은 실행되지 않습니다. 저장소와 기존 코드는 다음 요청을 위해 보관합니다.

### 보관된 이전 설정

| 영화 | 극장 | 상영관 | 상영 날짜 |
| --- | --- | --- | --- |
| 어벤져스: 엔드게임 앙코르 | CGV 왕십리 | SCREENX | 2026-09-25 |

위 설정은 현재 중지되어 있습니다. 재개하려면 대상 영화·날짜를 다시 확인하고 명시적으로 새 알림을 등록해야 합니다.

## 동작

- 감시를 새로 등록하고 Cron을 활성화할 때만 Cloudflare Workers Free에서 공개 CGV 상영정보를 조회합니다. 스케줄러 지연과 CGV 접근 제한이 있어 정확히 60초 이내 알림을 보장하지 않습니다.
- 예매 가능한 신규 SCREENX 회차를 발견하면 Discord Embed로 즉시 보냅니다. 등록 시 이미 열린 회차도 한 번 알립니다.
- 성공적으로 알린 회차를 Cloudflare D1에 저장하여 다음 실행과 재배포 이후에도 중복을 막습니다. D1 잠금으로 동시 요청을 막습니다.
- 403·429·CAPTCHA·Challenge·파싱 오류 시 조회를 중단하고 5→15→30→60→120분 대기합니다. 오류 알림은 6시간 동안 중복 방지하며 복구 시 한 번 알립니다.
- 정상적인 영화/회차 없음은 오류가 아닙니다. Discord 전송 실패 시 회차를 완료 처리하지 않고 다음 조회에서 다시 시도합니다.
- 2026-09-26 00:00 KST부터 CGV 조회를 종료합니다.
- 로그인·계정 쿠키·자동 예매·좌석 선택·결제·차단 우회 기능은 없습니다.

## 보안과 실행

실제 `DISCORD_WEBHOOK_URL`은 **Cloudflare의 암호화된 Secret**에만 저장합니다. 코드와 로그에는 출력하지 않습니다. `.env`, `.dev.vars`는 Git에서 제외합니다. GitHub Actions는 코드 테스트만 실행하며 CGV 조회나 Discord 전송을 하지 않습니다.

실행 코드 및 운영 안내: [cloudflare/README.md](cloudflare/README.md)

```sh
node --test cloudflare/worker.test.mjs
```

이전 감시 설정·회차 상태와 사용하지 않는 Python 감시 코드·워크플로·응답 파일은 현재 버전에서 제거했습니다. Git 커밋 이력과 Cloudflare의 과거 운영 로그는 서비스의 보존 정책에 따라 남을 수 있습니다.
