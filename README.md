# CGV 개인 예매 알림

**개인용 상영 스케줄 알림 도구이며 자동 예매 기능 없음**

## 감시 대상

| 영화 | 극장 | 상영관 | 상영 날짜 |
| --- | --- | --- | --- |
| 어벤져스: 둠스데이 | CGV 왕십리 | IMAX | 2026-12-16 및 이후 공개 상영일 |

2026-10-14 사용자 요청으로 상영 시작 기준을 2026-12-16으로 설정했습니다. 예매 오픈 날짜는 제한하지 않고 지금부터 감시합니다. 12월 16일 및 이후의 공개 IMAX 회차가 미리 예매 가능해져도 즉시 알립니다. 이전 오디세이·엔드게임 감시는 재개하지 않습니다.

## 동작

- Cloudflare Workers에서 1분마다 공개 예매 영화 목록을 확인합니다. 영화명은 `어벤져스: 둠스데이`, `Avengers: Doomsday`의 구두점·공백 차이를 정규화해 정확히 비교합니다.
- 영화가 목록에 등장하면 왕십리의 실제 공개 상영 날짜들을 조회하고, IMAX관·미래 회차·예매 제한 없음·잔여석 있음 조건을 확인합니다. 일반관·SCREENX·4DX와 다른 어벤져스 영화는 제외합니다.
- 예매 가능한 신규 회차를 발견하면 Discord Embed를 즉시 보냅니다. 처음 등록했을 때 이미 열린 회차도 한 번 알립니다.
- 성공적으로 알린 회차를 Cloudflare D1에 저장하여 다음 실행과 재배포 후에도 중복을 방지합니다. 날짜가 다른 같은 시각의 회차는 구별합니다.
- 등록된 날짜가 많으면 한 실행에서 최대 10개 날짜 또는 약 2분까지 처리하고, 다음 실행에서 남은 날짜를 이어 확인합니다. 스케줄러 지연·대상 날짜 수·CGV 접근 제한 때문에 정확히 60초 이내 감지를 보장하지는 않습니다.
- 403·429·CAPTCHA·Challenge·파싱 오류가 발생하면 추가 CGV 요청을 중단하고 5→15→30→60→120분 대기합니다. 오류 알림은 6시간 중복 방지, 정상 복구 알림은 한 번 전송합니다.
- 정상적인 영화/회차 없음은 오류가 아닙니다. Discord 전송 실패 시 해당 회차를 완료 처리하지 않아 다음 순회에서 재시도합니다.
- 로그인·계정 쿠키·자동 예매·좌석 선택·결제·차단 우회 기능은 없습니다.

## 실행과 보안

Cloudflare Workers Free와 D1을 사용합니다. 컴퓨터나 Codex를 꺼도 자동 실행되며, 감시를 위해 대시보드 로그인을 유지할 필요가 없습니다. GitHub Actions는 코드 테스트만 수행합니다.

실제 `DISCORD_WEBHOOK_URL`은 **Cloudflare의 암호화된 Secret**에 저장하며 코드·로그·오류 메시지에 출력하지 않습니다. `.env`, `.dev.vars`는 Git에서 제외합니다. 공개 HTTP 요청은 404로 처리하고, 운영 Worker에는 관리자 또는 테스트 전송 경로를 공개하지 않습니다.

운영 방법: [cloudflare/README.md](cloudflare/README.md)

```sh
node --test cloudflare/worker.test.mjs
```
