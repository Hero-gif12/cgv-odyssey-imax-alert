# Cloudflare 개인 CGV 알림

**개인용 상영 스케줄 알림 도구이며 자동 예매 기능 없음**

## 현재 등록

- 영화: 어벤져스: 둠스데이 / Avengers: Doomsday
- 극장: CGV 왕십리 (`0074`)
- 관: IMAX
- 상영 날짜: 2026-12-16 및 이후 CGV에 공개된 실제 상영일 (사용자 지정 개봉일 기준)
- 감시 시작: 지금부터. 예매 오픈 날짜는 제한하지 않음
- 주기: `* * * * *` (1분), `MONITOR_ENABLED=true`

## 구성

- `worker.mjs`: 공개 영화·날짜·회차 조회, 정확한 조건 판별, Discord 전송, 오류 대기
- `worker.test.mjs`: 합성 자료로 영화·극장·날짜·IMAX 구분, D1 영속 중복 방지, 잠금, 장애·재시도 검사
- `schema.sql`: D1 상태 테이블
- `wrangler.jsonc`: 기존 Worker와 D1 바인딩, 자동 실행 구성

D1 바인딩은 `DB`, 알림 Secret은 `DISCORD_WEBHOOK_URL`, 실행 스위치는 `MONITOR_ENABLED`입니다. 무료 플랜을 유지하며 유료 API는 사용하지 않습니다.

## 공개 데이터 조회

2026-10-08 CGV 공식 예약 화면의 클라이언트 코드와 Cloudflare 실제 HTTP 응답으로 확인한 요청만 사용합니다.

1. `searchAtktTopPostrList`: 날짜 필터 없는 공개 예매 영화 전체 목록. 대상 영화가 없으면 여기서 정상 종료합니다.
2. `searchSiteScnscYmdListBySite`: 대상 영화가 있을 때 왕십리에 공개된 상영 날짜를 가져옵니다.
3. `searchMovScnInfo`: 실제 날짜별 영화·상영관·시간·예매 제한·잔여석을 확인합니다.

CGV BFF 경로는 `https://cgv.co.kr/api/v1/booking/`입니다. 로그인이나 개인 쿠키를 전송하지 않습니다. 한 실행에서 최대 10개 날짜 또는 약 2분까지 처리하고 D1 커서로 남은 날짜를 이어 확인합니다. 차단이나 응답 구조 변경은 정상적인 회차 없음과 구별하며 요청을 중단합니다.

## 상태와 중복 방지

`monitor_state`의 1번 행에 등록 키, 전송한 회차, 처리할 날짜 위치와 오류 상태를 저장합니다. 기존 종료된 알림 이력은 보관하되 현재 `TARGETS`에 있는 둠스데이만 조회합니다. 동일 대상 재배포 시 이력을 초기화하지 않습니다. 새 등록 키일 때만 기존 오류 대기 상태를 해제합니다.

D1 원자적 잠금으로 중복 실행을 방지합니다. Discord 성공 응답 후 회차를 저장하며 실패한 전송은 다음 순회에서 재시도합니다. Discord 전송 직후 프로세스가 중단되어 D1 저장에 실패하는 드문 경우에는 중복 전송 가능성이 있습니다. 외부 전송과 데이터베이스 저장 사이의 원자적 처리는 보장하지 않습니다.

## 운영

중지: Cloudflare 설정에서 `MONITOR_ENABLED=false`로 저장하고 Cron 트리거를 제거합니다. 새로 재개할 때는 코드의 대상과 공개 데이터 응답을 확인한 뒤 활성화합니다.

CGV 오류는 5→15→30→60→120분 대기하며 다음 실행에도 이 상태를 유지합니다. 같은 장애의 Discord 알림은 6시간 제한, 복구 알림은 한 번입니다. 로그 시각은 KST입니다.

공개 Worker 요청은 항상 404입니다. 설치 검증은 로그인된 Cloudflare 편집기의 미리보기에서 수행했고 운영 코드에는 테스트·관리 경로가 없습니다. 이전 `PREFLIGHT_TOKEN`은 운영 코드에서 사용하지 않습니다. Discord Secret을 코드나 로컬 파일에 복사하지 않습니다.
