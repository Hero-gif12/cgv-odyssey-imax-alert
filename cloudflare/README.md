# Cloudflare 개인 CGV 알림

**개인용 상영 스케줄 알림 도구이며 자동 예매 기능 없음**

외부 라이브러리 없이 JavaScript Worker와 무료 D1을 사용합니다. 조회 대상과 영화 판별 규칙은 `worker.mjs`의 `TARGETS`에 있습니다. 기존 Python의 용산 9월 23일 상태 키를 유지합니다. 왕십리는 실제 CGV 표기인 `어벤져스-엔드게임 앙코르`도 정확히 비교합니다.

## 운영 구조

- Cloudflare Cron을 매분 실행하도록 설정합니다. 실행마다 두 극장을 순서대로 한 번씩 조회하며, 새 회차는 발견 즉시 Discord Embed로 보냅니다. 예약 시각은 지연될 수 있어 정확한 60초 전달을 보장하지 않습니다.
- D1의 한 행에 전송 완료 회차, 실패 횟수, 다음 재시도, 최근 조회 결과를 저장합니다. 조건부 UPDATE로 180초 잠금을 잡아 동시 실행을 막습니다. 재배포나 실행 환경 교체 후에도 같은 D1 바인딩을 유지해야 합니다.
- 기본 60초 주기에는 5초의 스케줄 지연 허용 범위를 둡니다. 중복 수동 호출은 대기합니다.
- 403/429/CAPTCHA/Challenge/데이터 오류가 나면 이후 CGV 요청을 중단하고 5·15·30·60·120분 대기합니다. 오류 알림은 6시간 중복 억제, 복구 알림은 한 번입니다. 접근 제한을 우회하지 않습니다.
- Discord 전송에 실패한 회차는 완료로 기록하지 않아 다음 조회에서 다시 알립니다. 전송 직후 저장되기 전에 실행이 강제 종료되는 드문 경우까지 원자적인 단 한 번 전송을 보장하지는 않습니다.
- 2026-09-24 00:00 KST부터 CGV 조회를 중단합니다.

## 비밀값과 활성화

`DISCORD_WEBHOOK_URL`은 Cloudflare Worker **Secret**에만 넣습니다. GitHub Actions Secret은 Cloudflare로 자동 복사되지 않습니다. `.dev.vars`, `.env`는 Git에서 제외됩니다. 요청 원문, 인증 헤더, Webhook URL은 로그로 출력하지 않습니다.

이 계정에서는 실제 CGV 응답과 Discord 연결 확인, 기존 `state.json` 이전 후 `MONITOR_ENABLED=true`와 매분 Cron을 등록했습니다. 새 환경에 구축할 때는 두 설정을 끄고 같은 검증 및 상태 초기화를 먼저 진행하세요. GitHub Actions의 예약 실행은 제거했습니다. 기존 Python workflow는 `CGV_LEGACY_MONITOR_ENABLED=true`를 별도로 등록해야 실행되는 수동 복구용입니다. 두 환경을 동시에 켜지 마세요.

이전용 관리자 경로는 인증 Secret이 필요하며 2026-09-18 19:00 KST에 자동 만료됩니다. 일반 공개 HTTP 요청은 404입니다. 이전 완료 후 예약 실행에는 관리자 경로가 필요하지 않습니다.

검증 시점의 결과이며 현재 예매 가능 여부는 CGV에서 확인하세요. `parser-fixtures.json`은 해당 응답에서 판별에 필요한 공개 상영정보만 보관하며, Python 판별 결과와 비교하는 테스트에 사용합니다.

```sh
node --test --test-isolation=none cloudflare/worker.test.mjs
python3 -m unittest discover -s tests -v
```

JavaScript 테스트는 실제 응답 비교, 다른 영화/날짜/관 제외, 실행 간 중복 방지, DB 잠금, 오류 시 추가 요청 중단, 오류 알림 억제와 복구, Discord 실패 후 재시도를 확인합니다. 오류 응답 테스트는 모의 응답이며 실제 차단을 유발하지 않습니다.

Cloudflare Free의 사용량 한도 내에서 운영하며 유료 플랜을 신청하지 않습니다. CGV가 이 실행 환경도 차단할 경우 감시 불가 알림과 대기 처리를 하며 예매 오픈을 보장할 수 없습니다.
